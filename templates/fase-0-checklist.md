# Fase 0 — Checklist de Preparação

Fazer **antes** de iniciar a Semana 1. Estimativa: 1 dia.

## Infraestrutura

- [ ] Criar organização no GitHub (ex: `freitas-data-engineering`)
- [ ] Criar repositório `portfolio-overview` (este) e deixar público
- [ ] Criar conta AWS Free Tier
- [ ] Configurar billing alert em US$ 5 na AWS (proteção contra custo inesperado)
- [ ] Confirmar acesso a Databricks (Community Edition ou trial)
- [ ] Instalar Terraform localmente (`terraform -version` funcionando)

## Processo

- [ ] Definir os 3 dias fixos de postagem (sugestão: Terça / Quinta / Sábado)
- [ ] Copiar `templates/README-projeto.md` para uso em cada repositório semanal
- [ ] Revisar `templates/calendario-editorial.md` e ajustar datas reais no calendário pessoal
- [ ] Bloquear os horários fixos na agenda (manhã 05h30-07h nos dias de gym já ocupados; usar noite 20h-22h como bloco principal)

## Comunicação

- [ ] Escrever e publicar o post de abertura de jornada (anúncio público do compromisso de 12 semanas — cria accountability)
- [ ] Atualizar o título/resumo do perfil LinkedIn para refletir o foco em Data Engineering (se ainda não refletir)

## Validação Final da Fase 0

- [ ] Este README mestre (`portfolio-overview`) está publicado e acessível
- [ ] Você consegue, em 1 frase, explicar o objetivo do programa para alguém de RH (treine isso agora)
